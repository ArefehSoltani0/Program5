🔢 Fibonacci Sequence Generator (Recursive)

A simple C# console application that computes and prints the first *n* Fibonacci numbers **in reverse order** (from the *n*-th term down to the 1st), using a **recursive** implementation.

Designed for educational purposes to demonstrate recursion in C#.

---

 📌 Example

Input: `6`  
→ Computes the first 6 Fibonacci numbers: `1, 1, 2, 3, 5, 8`  
→ Prints them in reverse:  
```
8 5 3 2 1 1
```

> ✅ Follows the classic Fibonacci definition:  
> `F(1) = 1`, `F(2) = 1`, `F(n) = F(n−1) + F(n−2)` for `n > 2`

---

 🛠️ Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) (e.g., .NET 6 or later)
- Any C#-compatible IDE or text editor (e.g., Visual Studio, VS Code, Rider)

---

 ▶️ How to Run

1. Save the code in a file named `Program.cs`.
2. Open a terminal in the project directory.
3. Compile and run:

   ```bash
   dotnet run
   ```

4. Enter a positive integer when prompted.
